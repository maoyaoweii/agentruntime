# 沙箱与命令（dsh-go 适配版）

Mika 原版的路径和工具名与这台机器不符，这里按本机实际环境重写。

## 环境

- 运行在 Ubuntu 24.04（proot，免 Root），有 bash / git / python / apt。
- 默认工作目录 `/root/workspace`。会话目录、`@` 引用、AGENTS 和 skills 用的是
  同一个绝对路径，在 shell 里同名可见。
- 应用自带的技能在 `/root/.dsh/skills/`。这些是 App 每次启动会重写的托管副本：
  **不要原地改它们**——你的修改会在下次启动时被覆盖。要写自己的东西就放到
  `/root/workspace` 下。
- 网络：可以联网（`curl` / `git` / `npm` 都能用），但出口带宽和时长有限制。

## 跑命令

- 命令是非交互执行的，默认超时 60 秒，最多 600 秒。超过就拆成几步，或者把慢活
  放到后台并重定向输出（`nohup cmd >log 2>&1 &`）。
- 长输出会被截断成头尾两段；完整输出保存在文件里，路径通过 `fullOutputPath`
  返回，需要全文就读那个文件。
- 装系统包用 `apt-get`，需要时加 `sudo`。大规模编译前先看 `df -h` 有没有空间。

## 别做的事

- 不要试图改 `/root/.dsh/skills/` 下的托管技能。
- 不要在没有备份的情况下覆盖用户已经在 `/root/workspace` 里的文件。
- 不要为了绕过权限或确认去改系统配置。
