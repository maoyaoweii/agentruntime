# DSH Mobile attribution

DSH Mobile is an independent native Android implementation in AgentRuntime. Its architecture is inspired by DeepSeek Harness, published by DeepSeek under the MIT license:

- https://github.com/deepseek-ai/deepseek-harness
- Reference revision: `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`

The Android implementation was written for this repository; no upstream Node/Cordis runtime source or official logo is bundled. This project is not affiliated with or endorsed by DeepSeek, and does not claim binary or plugin compatibility with the desktop harness. The original repository's license remains applicable to its existing code.

The mobile interaction design also takes inspiration from [ccch1mneyyy/dsh-go](https://github.com/ccch1mneyyy/dsh-go/tree/b96322910c9ebd1ae10ac89283ba1f28c3c904f2), particularly its compact completed-tool timeline and adaptive layout. Its source is AGPL-3.0 with separate terms for named assets; no dsh-go code, images, mascots, or logos are included here.
