# 微信（com.tencent.mm）

## 包名
- 微信：`com.tencent.mm`
- 桌面（Launcher）上按可见名「微信」启动时，用包名启动，不要点图标。

## 界面结构（常见叫法）
- 底部 tab 常见为：微信 / 通讯录 / 发现 / 我（英文版可能是 Chats / Contacts / Discover / Me）。
- 顶部右上角通常是「搜索」或放大镜图标；部分版本是顶部搜索框。
- 搜索会**同时**出联系人、群聊、聊天记录三类结果，需要在结果里看清区分再点。

## 容易误判的地方
- **草稿不等于已发送**：输入框里有字只说明写进去了，必须看到消息出现在会话里才算发送成功。
- 发送后应在会话末尾看到这条消息；看不到就不能报成功。
- 「发送」按钮在输入框右侧；英文版可能是 Send。

## 无障碍
- 微信大量使用自绘控件，无障碍树**经常是空树或只有一两个节点**。
- 空树时主循环必须在同一轮改看图识字，不要停下来让用户去开无障碍开关，也不要断言"微信禁止读屏"。
- 看图识别出的文字可能错字、乱序，只能当线索；不能据此判断某个位置一定可点击。

## 边界
- 不读私聊去判断别人的情绪；用户明确要求整理"ta 说了什么"时，只做客观转述。
- 付款、转账、发红包进入待确认，不自动点确认。
